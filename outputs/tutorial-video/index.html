如何启动 · Quickstart
🍎 macOS
cd webapp
python3 -m venv .venv
.venv/bin/pip install --no-index --find-links wheels/ \
  fastapi uvicorn pydantic python-multipart watchfiles httpx
cp .env.example .env  # 填入 ANTHROPIC_API_KEY
./start-webapp.command        # 或双击此文件
🪟 Windows
cd webapp
python -m venv .venv
.venv\Scripts\pip install --no-index --find-links wheels\ ^
  fastapi uvicorn pydantic python-multipart watchfiles httpx
copy .env.example .env   :: 填入 ANTHROPIC_API_KEY
start-webapp.bat              :: 或双击此文件
wheels/ 已预打包 · 无需联网安装 · Python 3.13 + Node 24（前端 dev 模式可选）
